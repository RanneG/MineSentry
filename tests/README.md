# Tests Directory

This directory contains test scripts for the MineSentry application.

## Test Scripts

- `test_detection.py` - Test the detection pipeline directly
- `test_api_detection.py` - Test the detection pipeline via API
- `testnet_trial.py` - Test Bitcoin testnet integration
- `test_detection_flow.sh` - Quick status check script
- `test_detection_pipeline.sh` - Full pipeline test script
