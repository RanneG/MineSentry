# Utility Scripts

This directory contains utility scripts for setup, maintenance, and development.

## Setup Scripts

- `setup_bounty_contract.py` - Initialize the bounty contract
- `fund_bounty_contract.py` - Fund the bounty contract
- `verify_setup.py` - Verify system setup

## Development Scripts

- `create_test_reports.py` - Create test reports for development
- `get_testnet_data.py` - Fetch testnet data from mempool.space
- `example_client.py` - Example API client usage
- `deploy.py` - Deployment helper script

## Maintenance Scripts

- `start_bitcoind_testnet.sh` - Start Bitcoin Core in testnet mode
- `fix_database_permissions.sh` - Fix database file permissions

## Usage

These scripts are typically used during development and deployment setup.
Refer to the main documentation in `../../docs/` for context.
